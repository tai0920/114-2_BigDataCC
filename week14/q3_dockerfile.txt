=== 觀念題 ===
Q1：Dockerfile 中 RUN 和 CMD 有什麼不同？分別在什麼時候執行？
A1：RUN 是在建立映像檔時執行的指令，通常用來安裝套件、建立資料夾或設定環境。例如 RUN pip install -r requirements.txt 會在 docker build 時執行，並把結果存進映像檔。CMD 是在容器啟動時執行的預設指令，例如 CMD ["python", "app.py"] 會在 docker run 時執行，用來啟動應用程式。簡單來說，RUN 是 build 階段執行，CMD 是 container run 階段執行。

Q2：為什麼要先 COPY requirements.txt 安裝套件，再 COPY . . 複製程式碼？
   如果反過來，每次改 app.py 時會多做什麼事？
A2：先 COPY requirements.txt 再安裝套件，是為了善用 Docker 的 build cache。因為套件清單通常不會頻繁修改，所以 Docker 可以重複使用已經安裝好套件的快取層，讓之後 build 更快。
如果先 COPY . . 再安裝套件，當 app.py 只要有任何修改，Docker 就會判定前面的檔案層改變，導致 pip install 重新執行。這樣每次只是改程式碼，也會重新安裝 Flask 等套件，浪費時間並降低建置效率。
